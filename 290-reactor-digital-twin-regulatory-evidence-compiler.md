# Reactor Digital Twin Regulatory Evidence Compiler

## Goal
Compile a nuclear digital twin's models, sensors, uncertainty, software changes and operating role into reviewable regulatory evidence.

## Pipeline
`intended use -> hazards -> models/data -> V&V -> uncertainty -> change control -> operational monitoring -> evidence dossier`

## Value
The bottleneck for safety-significant twins is not visualization but demonstrating controlled, auditable trust.

## Outputs
- requirement/evidence traceability
- unresolved evidence gaps
- model/sensor dependencies
- change impact
- review-ready dossier structure

## MVP
Condition-monitoring twin rather than direct autonomous control.
