# Grid Constraint Impact Analyzer

## Core idea
When a network asset, generator, storage site or operating rule changes, automatically identify which grid constraints, studies and operational decisions become affected.

## Product
Maintain a dependency graph linking topology, contingencies, protection assumptions, thermal/voltage/stability constraints, forecasts and planning studies. A change triggers targeted re-analysis rather than a blanket rerun.

## Buyers
Utilities, system operators, renewable/storage developers and engineering consultants.

## Value
Power-system studies are expensive and frequently repeated. Scientific change-impact analysis can reduce unnecessary computation while preventing stale studies from being reused after material network changes.

## Synergy
Scientific Change-Impact Analyzer + Semantic Build Cache + Grid Model Interoperability Compiler.
