# Scientific Portfolio Capital Allocation Engine

Given hundreds of product/research ideas, limited developers, compute and cash, choose a portfolio that maximizes expected strategic and financial value.

Model dependencies, shared-core leverage, time-to-proof, probability of success, buyer value, IP moat and option value.

Outputs: build order, parallel tracks, kill criteria, milestone funding and sensitivity analysis.

This is the meta-layer that converts the Ideas repository itself into an executable R&D strategy.
