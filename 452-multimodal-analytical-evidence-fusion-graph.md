# Multimodal Analytical Evidence Fusion Graph

Fuse spectroscopy, chromatography, microscopy, mass spectrometry, elemental analysis and process metadata into a single evidence graph.

Each analytical result keeps identity, calibration, uncertainty and causal/provenance links.

Queries:
- which technique actually supports this composition claim?
- where do methods disagree?
- which extra measurement would resolve the conflict?
- which conclusion becomes stale after a calibration change?
