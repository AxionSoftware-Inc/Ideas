# Sensor Semantic Calibration IR

Represent a sensor as more than a channel name and calibration constant.

Core objects: measurand, transfer function, units, range, bandwidth, cross-sensitivities, calibration history, mounting/package state, uncertainty, drift mechanisms, environment and evidence.

This becomes the shared identity layer for calibration, sensor fusion, virtual sensing, diagnostics and qualification.

**MVP:** temperature/pressure/inertial sensors with versioned calibration and deployment context.
