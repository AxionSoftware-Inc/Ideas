# Soil Sensor Fusion & Missing-State Estimator

## Idea
Infer unmeasured soil and root-zone states from sparse heterogeneous sensors plus process models.

## Inputs
- moisture/temperature/EC sensors
- weather
- irrigation history
- soil profile
- crop state

## Outputs
- root-zone moisture/nutrient estimates
- uncertainty
- sensor fault detection
- value of adding/moving sensors

## Buyers
Precision agriculture, irrigation systems and greenhouse operators.

## Moat
Physics-constrained state estimation and sensor-value reasoning.
