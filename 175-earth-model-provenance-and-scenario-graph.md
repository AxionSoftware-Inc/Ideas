# Earth Model Provenance & Scenario Graph

## Core idea
Represent every climate/geoscience indicator as a dependency graph linking scenario, global model, ensemble member, downscaling method, bias correction, observations, impact model and post-processing.

## Product
A user can click a flood-risk or wind-energy number and trace exactly how it was produced. If one upstream dataset/model changes, the system identifies every affected downstream map, report and decision.

## Buyers
Climate services, governments, insurers, engineering firms, renewable developers and research consortia.

## Strategic value
Climate products are complex chains rather than single models. Provenance plus semantic change-impact analysis can become a trust and maintenance layer across many existing data providers.
