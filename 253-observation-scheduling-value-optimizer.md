# Observation Scheduling Value Optimizer

## Idea
Choose telescope, satellite or mission observations by expected scientific information value rather than simple priority queues.

## Inputs
- hypotheses/models
- uncertainty state
- instrument capabilities
- visibility/resource windows
- weather/environment constraints
- competing observation requests

## Outputs
- information gain per unit time/cost
- schedule
- opportunity cost
- hypothesis-discrimination value
- expected uncertainty reduction

## Buyers
Observatories, Earth/space missions and scientific facilities.

## Moat
Evidence-aware experiment design combined with real operational constraints.
