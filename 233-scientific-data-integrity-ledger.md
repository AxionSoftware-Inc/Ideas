# Scientific Data Integrity Ledger

## Problem
Scientific results pass through acquisition, preprocessing, calibration, transformation, filtering and analysis. A later change or corruption may be hard to localize.

## Product
Maintain tamper-evident lineage for datasets, transformations, calibration state, software versions and approvals, while keeping bulk data outside the ledger.

## Buyers
Research labs, regulated R&D, autonomous labs, publishers and industrial test organizations.

## Material value
Faster forensic recovery, stronger auditability and higher trust in reused datasets.

## Moat
Scientific semantics: the ledger knows what a transformation means, not only that a file hash changed.

## MVP
Track one experiment from raw acquisition through processed result with signed manifests and reproducible transformations.
