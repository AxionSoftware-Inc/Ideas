# AM Defect Causality & Counterfactual Engine

Given a pore, crack, lack-of-fusion region, distortion or surface defect, reconstruct plausible causal paths across feedstock, machine state, geometry and process conditions.

Then estimate counterfactuals:
- would changing parameter X have prevented it?
- was the defect geometry-driven or machine-driven?
- what minimum process change should be tested?

Useful for learning from failed builds.
