# Device-to-System Performance Compiler

## Thesis
Translate component-level photonic measurements/simulations into system-level consequences automatically.

## Example
A modulator's measured loss, bandwidth and nonlinearity changes -> recompute link budget, BER/power implications, thermal load and calibration needs.

## Why valuable
Device teams and system teams often optimize different metrics. This compiler maintains the dependency graph between them.

## Buyers
Optical communications, sensing, photonic computing.

## MVP
PIC component model -> simple optical link/system metrics with uncertainty propagation.
