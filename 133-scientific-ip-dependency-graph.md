# Scientific IP Dependency Graph

## Thesis
Track which models, equations, datasets, software components, patents, licenses and proprietary calibrations contribute to a scientific/engineering product.

## Graph
`product -> model -> implementation -> dataset -> parameter set -> source/license/patent`

## Outputs
- dependency provenance
- license conflicts
- redistribution constraints
- replacement candidates
- components that create unique proprietary value

## Buyers
Deeptech companies, R&D legal/IP teams, technology-transfer offices.

## Strategic value
Makes the scientific stack auditable for licensing, acquisition, due diligence and commercialization.
