# Turbulence Model Applicability Mapper

## Problem
Selecting RANS/LES/DES closures is expert-heavy and model choice can silently dominate error outside familiar regimes.

## Product
Given geometry, Reynolds/Mach numbers, separation, wall resolution, available compute and target outputs, rank turbulence-model choices with applicability warnings and evidence.

## Buyers
CFD teams, engineering consultancies, aerospace and turbomachinery groups.

## Material value
Reduce solver trial-and-error and inappropriate closure selection.

## Moat
Evidence-linked regime knowledge plus historical case performance.

## MVP
Support several canonical flows and a small set of common turbulence models.
