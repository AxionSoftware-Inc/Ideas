# Scientific Method Skill Passport

## Idea
Create a portable evidence record showing how well a learner or researcher performs core scientific-method tasks across domains.

## Skills
- hypothesis formulation
- falsifiable prediction
- control selection
- confound identification
- experiment design
- evidence grading
- uncertainty reasoning
- conclusion calibration

## Evidence sources
Interactive cases, virtual labs, real project artifacts and reviewed experiments.

## Buyers
Universities, research internships, labs and technical employers.

## Moat
Cross-domain verified scientific reasoning profile rather than grades or certificates.
