# Monitoring Network Value-of-Information Planner

## Goal
Choose where additional environmental sensors/samples reduce decision uncertainty enough to justify their cost.

## Engine
`current posterior + candidate observations + decision model + sample cost -> expected decision value`

## Uses
- groundwater wells
- river gauges
- air-quality stations
- water-quality sampling
- flood sensors

## Output
Ranked locations, variables, frequencies and expected uncertainty reduction.

## MVP
Small groundwater monitoring network.
