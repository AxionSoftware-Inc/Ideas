# Condition-Monitoring Sensor Placement Optimizer

## Goal
Choose sensor locations and types based on fault detectability and decision value rather than convenience.

## Inputs
Dynamic model, candidate faults, operating regimes, noise, sensor costs and maintenance access.

## Outputs
- minimum sensor set
- probability of detecting each fault
- redundancy
- blind spots
- value of an additional sensor

## Value
Reduces instrumentation cost while preserving diagnostic coverage.

## MVP
Rotating machine or structural modal model.
