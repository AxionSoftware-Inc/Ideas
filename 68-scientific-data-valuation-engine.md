# Scientific Data Valuation Engine

## Goal
Estimate the marginal value of a dataset, sensor stream or proposed measurement for a specific scientific or engineering decision.

## Questions it answers
- Is this new dataset actually useful?
- Which 5% of measurements drive most model improvement?
- Which sensor can be removed with minimal information loss?
- How much would another experiment reduce decision uncertainty?
- Which private dataset is worth licensing?

## Inputs
Model, task, current evidence, uncertainty, candidate data and acquisition cost.

## Output
A value score tied to downstream impact rather than file size or sample count.

## Business
Industrial data acquisition, sensor planning, scientific data marketplaces, digital twins and R&D budgeting.

## Strategic value
Creates an economic layer on top of the knowledge/evidence graph.
