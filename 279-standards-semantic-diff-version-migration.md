# Standards Semantic Diff & Version Migration

## Idea
Compare standard revisions by meaning and automatically map old compliance evidence to new requirements.

## Outputs
- added/removed/changed obligations
- threshold or definition changes
- renumbered-but-equivalent clauses
- newly invalid evidence
- reusable prior evidence
- migration checklist

## Buyers
Manufacturers, certification bodies and standards-heavy engineering organizations.

## Moat
Meaning-aware standard versioning linked to product/evidence graphs.
