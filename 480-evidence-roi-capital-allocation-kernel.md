# Evidence ROI & Capital-Allocation Kernel

A universal engine for deciding what evidence to buy next.

Inputs:
current belief/model uncertainty, candidate experiment/test/simulation, cost, duration, downstream decisions, commercial value and risk.

Output:
- expected value of each evidence action
- probability it changes the decision
- information gained per dollar/day
- recommended evidence portfolio
- stop/continue decision

This becomes the economic scheduler for the entire Scientific OS.
