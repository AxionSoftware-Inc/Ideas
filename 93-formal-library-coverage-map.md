# Formal Library Coverage Map

## Problem
Researchers rarely know which parts of a textbook, field or industrial theory are already formalized, weakly covered, duplicated, or completely missing.

## Product
Map an informal corpus onto formal libraries at theorem/definition granularity.

## Output
- formally covered statements
- partially aligned statements
- missing definitions
- missing lemmas blocking many downstream results
- alternative formalizations
- confidence/fidelity scores
- estimated effort to close each gap

## Uses
- plan formalization projects
- prevent duplicate work
- prioritize high-leverage missing mathematics
- benchmark AI formalizers on meaningful gaps
- quantify formalization progress for grants/research programs

## Moat
Combines informal/formal alignment, dependency structure and proof-cost estimates into a strategic map rather than a flat completion percentage.
