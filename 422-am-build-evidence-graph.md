# Additive Manufacturing Build Evidence Graph

Connect powder/feedstock, machine state, calibration, scan strategy, in-situ monitoring, geometry, post-processing, NDE, coupons and final properties for every build.

Queries:
- why is this part qualified?
- what changed between build A and B?
- which evidence is invalid after machine service?
- which sibling parts share the same risk?

This is the AM digital-thread trust backbone.
