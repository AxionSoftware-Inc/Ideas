# Mathematical Object Registry

## Thesis
Treat mathematical objects—groups, manifolds, operators, spaces, measures, tensor types, special functions—as stable semantic entities rather than names embedded in prose.

## Core record
Each object stores canonical identity, aliases, notation, definitions across formalisms, equivalent constructions, assumptions, parent/child structures, operators acting on it, important theorems, implementation/formalization links, and provenance.

## Product value
- foundation for semantic theorem search and equation understanding
- resolves naming collisions across textbooks and software
- lets agents ask for capabilities of an object instead of guessing APIs
- enables cross-library translation between Lean, SymPy, Sage, Mathematica-style notation, and domain packages

## Moat
The registry becomes a durable namespace/identity layer for the whole scientific ecosystem. Every later theorem, model, proof and dataset can reference stable object IDs.

## Business
Enterprise/private registries for proprietary mathematical models and engineering ontologies; API access for scientific software and AI systems.
