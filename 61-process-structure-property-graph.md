# Process-Structure-Property Causal Graph

## Thesis
Materials properties are not determined only by chemical composition. Processing changes microstructure, which changes properties and failure behavior.

Represent the chain explicitly:
```text
composition
 -> processing
 -> microstructure
 -> defects/phases
 -> properties
 -> component performance
 -> failure modes
```

## Capabilities
- explain why two samples of the same nominal material behave differently
- trace a desired property back to processing variables
- connect literature, microscopy, simulations and manufacturing records
- support causal rather than purely correlational materials AI

## Business
Advanced manufacturing, metallurgy, batteries, semiconductors, composites and additive manufacturing.

## Moat
The graph connects scientific evidence with real manufacturing history, creating a valuable industrial materials digital thread.
