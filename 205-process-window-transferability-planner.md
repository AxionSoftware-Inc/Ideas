# Semiconductor Process Window Transferability Planner

## Problem
A recipe that works on one chamber, fab, wafer stack or node may fail when transferred because hidden equipment/material/context assumptions changed.

## Product
Compare source and target manufacturing contexts, estimate which process-window dimensions transfer, which require recalibration and which experiments provide the most information.

## Buyers
Foundries, multi-site manufacturers, equipment vendors and technology-transfer teams.

## Material value
Reduce requalification wafers and accelerate copy-exact/process transfer.

## Moat
Semantic mapping of tool capability, materials, geometry, process physics and historical transfer evidence.

## MVP
Transfer one simplified deposition/etch recipe between two virtual tool profiles and generate a minimal recalibration plan.
