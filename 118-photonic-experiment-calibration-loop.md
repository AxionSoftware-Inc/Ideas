# Photonic Experiment Calibration Loop

## Thesis
Close the loop between simulated photonic devices and measured fabricated devices.

## Workflow
`design -> fabrication -> spectral measurement -> model discrepancy -> parameter/process inference -> calibrated model -> next design`

## Outputs
- inferred process shift
- model-vs-device residual structure
- uncertainty update
- recommended measurement or redesign

## Buyers
Photonics labs, foundries, PIC startups.

## Strategic value
Turns every fabricated wafer/device into data that improves the semantic process model rather than remaining a one-off measurement.
