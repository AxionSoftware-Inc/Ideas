# Lab Procedure Simulator & Preflight Tutor

## Idea
Let learners design a laboratory procedure, then simulate likely outcomes, hazards, measurement failures and missing controls before real lab access.

## Pipeline
`procedure draft -> instrument/reagent model -> preflight simulation -> diagnostics -> revision -> competency evidence`

## Value
Reduces wasted lab time and teaches operational scientific reasoning rather than memorized protocol steps.

## Buyers
Universities, training labs and technical schools.

## Moat
Shared infrastructure with the real experiment preflight engine, allowing training and production workflows to use the same semantics.
