# Proof Provenance Certificate

## Thesis
A theorem result should carry a machine-readable receipt describing not only that the kernel accepted it, but what assumptions, axioms, libraries, generated artifacts and external solvers contributed.

## Certificate
- exact theorem statement hash
- proof term / checker identity
- dependency closure
- axiom footprint
- imported package versions
- generated-code provenance
- external solver certificates
- human/AI contribution metadata
- reproducible build environment

## Value
- trust and auditability for AI-generated mathematics
- compliance for enterprise formal verification
- reproducible theorem publishing
- safe theorem reuse across organizations

## Strategic role
Model Passport for mathematics. It links theorem registries, scientific lockfiles, formalization fidelity, semantic versioning and reproducible research.

## Business
Signed private proof certificates and audit reports can be sold as enterprise verification infrastructure rather than consumer theorem proving.
