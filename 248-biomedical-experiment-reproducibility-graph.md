# Biomedical Experiment Reproducibility Graph

## Idea
Capture the full dependency graph behind biomedical experiments: samples, preparation, instruments, assays, batches, preprocessing, statistics, models and conclusions.

## Core value
When one protocol, reagent lot, threshold or software version changes, identify exactly which results and claims need revalidation.

## Outputs
- lineage and provenance
- batch-effect dependencies
- reagent/instrument impact
- reproducibility gaps
- stale claims
- replay package

## Buyers
Biotech, pharma, CROs and academic core facilities.

## Moat
Experiment-to-claim dependency semantics rather than document-level provenance.
