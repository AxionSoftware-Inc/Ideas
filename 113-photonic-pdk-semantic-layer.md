# Photonic PDK Semantic Layer

## Thesis
Create a machine-actionable semantic layer over photonic process design kits so design tools understand not only geometry rules but optical/electrical/thermal meaning, validity and fabrication evidence.

## Objects
waveguides, couplers, modulators, detectors, phase shifters, materials, wavelength bands, process corners, loss models, tolerances.

## Value
Enable portable design automation, verification and AI agents across foundry-specific PDKs without pretending that processes are identical.

## Buyers
Photonics design teams, EDA vendors, foundries.

## MVP
Normalize a small set of passive/active component metadata across two PDK-style libraries.
