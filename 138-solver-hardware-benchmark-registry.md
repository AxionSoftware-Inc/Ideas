# Solver / Hardware Benchmark Registry

## Thesis
Maintain evidence-backed performance profiles for scientific solvers on real hardware and problem classes.

## Key fields
solver/version, hardware, mesh/problem size, precision, memory use, convergence, runtime, energy, numerical error.

## Value
A benchmark should answer which hardware is efficient for *this scientific problem*, not which GPU has the largest generic score.

## Buyers
HPC centers, cloud providers, simulation teams, procurement groups.

## Strategic value
Feeds the Scientific Compute Broker and Numerical Solver Planner with empirical evidence.
