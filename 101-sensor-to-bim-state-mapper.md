# Sensor-to-BIM State Mapper

## Thesis
Map real sensor streams to physical BIM entities and inferred building states automatically.

## Problems solved
- Which sensor belongs to which room/equipment/object?
- Which physical quantity and coordinate/location does it measure?
- Which model state should consume it?
- Has the sensor moved, drifted or been replaced?

## Product value
Creates a live semantic bridge between static asset models and operational telemetry.

## Buyers
Facility management, digital twins, industrial campuses, smart buildings.

## MVP
Map temperature, power and HVAC telemetry to IFC spaces/equipment and flag ambiguous mappings.
