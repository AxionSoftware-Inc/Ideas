# Cross-Archive Astronomy Semantic Query Layer

## Idea
Query heterogeneous astronomy archives by physical meaning rather than archive-specific schema and column names.

## Examples
- all measurements constraining a stellar-mass estimate
- observations covering a target before/after an event
- spectra suitable for a specific line-ratio inference
- datasets with compatible calibration and resolution

## Core services
- object identity resolution
- coordinate/time normalization
- instrument semantics
- unit/frame conversion
- provenance-aware joins

## Buyers
Survey collaborations, observatories and astronomy platforms.

## Moat
Scientific-semantic federation across archives instead of another data portal.
