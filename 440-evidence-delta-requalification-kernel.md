# Evidence-Delta & Requalification Kernel

A universal engine for answering:

'Something changed. What evidence can we reuse, what became stale, and what is the minimum new validation required?'

Inputs:
semantic dependency graph + changed object + failure mechanisms + requirements + prior evidence.

Outputs:
- unaffected evidence
- invalidated evidence
- bridging evidence
- minimum requalification plan
- residual uncertainty

This primitive can power AM, welding, composites, nuclear, BIM, sensors, pharma-like regulated workflows and more.
