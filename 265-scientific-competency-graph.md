# Scientific Competency Graph

## Idea
Represent scientific competence as a graph of demonstrable skills rather than course completion or quiz scores.

## Examples
- dimensional analysis
- uncertainty propagation
- experiment design
- instrument setup
- model validation
- proof construction
- data interpretation
- reproducibility

## Evidence
Each skill is backed by tasks, simulations, artifacts or verified experiments.

## Buyers
Universities, technical training programs, laboratories and engineering employers.

## Moat
Evidence-backed skill ontology that connects learning to real scientific work.
