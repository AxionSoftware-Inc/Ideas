# Scientific Schema Synthesizer

## Thesis
Infer and propose a rigorous semantic schema for messy scientific datasets while preserving raw data and uncertainty about interpretation.

## Inputs
CSV/HDF5/JSON/files + papers/protocols + user annotations.

## Outputs
- entities/variables
- units and dimensions
- coordinate systems
- uncertainty fields
- missing-value semantics
- provenance links
- validation rules

## Value
Convert one-off lab datasets into reusable machine-actionable assets.

## Buyers
Labs, data repositories, industrial R&D, scientific AI teams.
