# Catalyst Scale-Up Transferability Compiler

Translate catalyst performance from powder/coupon/microreactor tests to pellets, monoliths, packed beds or industrial reactors.

`intrinsic kinetics + transport + heat release + geometry + deactivation + scale -> expected plant behavior`

Outputs:
- scale-up risk
- likely hotspot/selectivity shifts
- transport limitations
- minimum pilot evidence
- GO / PILOT / REDESIGN.
