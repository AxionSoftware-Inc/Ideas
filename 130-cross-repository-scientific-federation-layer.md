# Cross-Repository Scientific Federation Layer

## Thesis
Let users query heterogeneous scientific repositories as one semantic system without forcing all data into one central database.

## Core
- entity resolution
- schema mapping
- units/convention normalization
- access-policy awareness
- provenance-preserving joins
- federated search and computation

## Why now
Research infrastructures are increasingly federated, but interoperability remains a central goal and challenge.

## Buyers
Research infrastructures, national labs, consortia, large industrial R&D organizations.

## Moat
Scientific semantic query planning across distributed sources.
