# Scientific Model Poisoning / Anomaly Detector

## Problem
Scientific models can be corrupted by bad calibration data, maliciously altered training sets, swapped checkpoints or subtle upstream errors while still producing plausible outputs.

## Product
Monitor model/data provenance, physical invariants, benchmark residuals, parameter distributions and behavior shifts to detect suspicious scientific changes.

## Buyers
Industrial R&D, model registries, autonomous labs, HPC facilities and safety-critical engineering teams.

## Material value
Catch compromised or corrupted models before they contaminate downstream decisions.

## Moat
Physics/evidence-aware anomaly detection rather than generic file-integrity monitoring.

## MVP
Inject several data/model corruptions into a calibrated scientific model and detect them through mixed provenance + physics checks.
