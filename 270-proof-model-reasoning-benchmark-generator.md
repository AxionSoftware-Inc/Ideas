# Proof / Model Reasoning Benchmark Generator

## Idea
Generate adaptive scientific reasoning tasks from verified theorem/model graphs, with controlled difficulty and known solution evidence.

## Task types
- missing assumption
- invalid derivation
- counterexample
- model selection
- approximation validity
- proof strategy
- experiment design

## Buyers
Universities, hiring platforms and scientific-AI evaluation teams.

## Moat
Benchmarks generated from semantic scientific objects with machine-checkable answer keys rather than handcrafted static question banks.
