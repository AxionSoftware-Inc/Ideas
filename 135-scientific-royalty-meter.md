# Scientific Royalty Meter

## Thesis
Enable usage-based licensing of proprietary scientific assets while preserving attribution and dependency accounting.

## Meterable assets
- model packages
- calibrated parameter sets
- material-property datasets
- specialized solvers
- validated surrogate models
- experiment protocols

## Possible pricing
per simulation, per optimization, per device designed, per API call, per seat or enterprise license.

## Technical core
Signed asset identity + usage receipts + dependency graph + policy engine.

## Buyers
Scientific software marketplaces, universities, independent model creators, deeptech vendors.
