# Virtual Lab Skill Verifier

## Idea
Assess whether a learner can actually perform scientific procedures in an interactive virtual lab, not merely answer questions about them.

## Checks
- instrument selection
- setup sequence
- calibration
- controls
- measurement strategy
- uncertainty handling
- error recovery
- interpretation

## Output
A skill passport with demonstrated competencies, failure patterns and remediation tasks.

## Buyers
Universities, schools, workforce-training programs and laboratory employers.

## Moat
Procedure-level evidence and scientific reasoning telemetry.
