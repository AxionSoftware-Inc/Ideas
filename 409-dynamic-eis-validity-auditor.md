# Dynamic EIS Validity Auditor

Audit whether an impedance spectrum is physically and experimentally admissible for interpretation.

Checks:
- stationarity/non-stationarity assumptions
- linearity
- excitation amplitude
- drift relative to lowest frequency
- frequency-window sufficiency
- artefacts and synchronization
- model identifiability

Output is not merely 'fit quality' but whether the spectrum can support the claimed mechanism.
