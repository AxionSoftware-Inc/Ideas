# Acoustic Source Separation with Physics Provenance

## Idea
Separate observed sound/vibration into likely physical sources while preserving what evidence supports each attribution.

## Inputs
Microphone/accelerometer arrays, geometry, transfer paths, rotational orders and operating states.

## Outputs
- source contribution map
- transfer-path explanation
- uncertainty
- alternative hypotheses
- best additional sensor/test

## Value
Useful for NVH debugging and industrial noise reduction, where knowing the source is more valuable than detecting that noise increased.

## MVP
Rotating machine with several candidate source paths.
