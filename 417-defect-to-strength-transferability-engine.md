# Composite Defect-to-Strength Transferability Engine

Determine how a detected defect changes structural allowables for the actual load case.

Inputs:
defect morphology/location + laminate + environment + load spectrum + validated failure models.

Outputs:
- strength/life distribution
- defect criticality
- inspect/repair/use-as-is options
- transferability from coupon evidence to component

Avoid one-size-fits-all defect limits.
