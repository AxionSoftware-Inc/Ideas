# Quantum Algorithm Viability Gate

## Thesis
Before a team invests months implementing a quantum algorithm, test whether it has a credible path to outperform the best practical classical approach under realistic hardware/resource assumptions.

## Gate
- define task and success metric
- establish classical baseline
- estimate quantum resources
- model noise/mitigation overhead
- include data loading and readout costs
- test scaling sensitivity
- return GO / RESEARCH / NO-GO with evidence

## Buyers
Enterprises, investors, quantum teams, government R&D programs.

## Strategic value
A decision product that can save expensive speculative R&D.
