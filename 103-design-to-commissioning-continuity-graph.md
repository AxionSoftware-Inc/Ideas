# Design-to-Commissioning Continuity Graph

## Thesis
Maintain a dependency graph from design intent through BIM, analysis, procurement, installed equipment, commissioning tests and operational evidence.

## Why it matters
A design decision often loses traceability as the project passes through many tools and organizations.

## Graph edges
requirement -> model element -> calculation -> specification -> selected product -> installed asset -> commissioning test -> live performance

## Product value
When an element or product changes, compute which analyses, requirements and commissioning evidence became stale.

## Buyers
Large AEC projects, infrastructure owners, data centers, hospitals, EPC firms.
