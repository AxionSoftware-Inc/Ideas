# Building Performance Digital Twin Compiler

## Thesis
Compile BIM + installed equipment + live sensors into a calibrated building-performance twin.

## Outputs
- thermal zones
- HVAC topology
- occupancy/load model
- energy flows
- inferred hidden states
- model uncertainty
- drift alarms
- calibration status

## Strategic value
Connect design-time BIM to operational data instead of creating a separate twin that loses design semantics.

## Buyers
Large building owners, campuses, data centers, hospitals, energy-service companies.

## MVP
Import BIM + hourly temperature/energy data -> auto-calibrate a zone thermal model and identify abnormal energy behavior.
