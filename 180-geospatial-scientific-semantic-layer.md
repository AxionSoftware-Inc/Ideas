# Geospatial Scientific Semantic Layer

## Core idea
Represent geospatial scientific data by physical meaning, support volume/area, vertical coordinate, reference frame, time semantics, uncertainty and observation/model provenance—not only file format and coordinate reference system.

## Product
Make it possible to safely query and combine fields such as precipitation, soil moisture, groundwater head, wind, emissions, material exposure or hazard indicators without silent mismatches in grids, averaging periods, vertical datum or physical definition.

## Buyers
Climate/environment platforms, utilities, engineering, agriculture, insurers and geospatial software vendors.

## Moat
This is the Earth-domain extension of Scientific Semantic IR and a foundational adapter for federated data, models and local decision products.
