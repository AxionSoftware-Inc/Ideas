# Microscope Instrument-State Passport

Maintain a living passport for microscope performance.

Track illumination stability, stage accuracy, PSF, chromatic registration, detector noise, flat-field response, objective condition, calibration standards and maintenance history.

Output:
- current performance state
- deviations from baseline
- which measurements remain valid
- which experiments require recalibration
- evidence before/after service

**Value:** converts microscope QC from occasional SOP checks into machine-readable measurement assurance.
