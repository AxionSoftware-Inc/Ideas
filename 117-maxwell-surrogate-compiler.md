# Maxwell Surrogate Compiler

## Thesis
Compile expensive electromagnetic simulations into fast surrogate models while preserving a machine-readable validity domain and error certificate.

## Pipeline
`high-fidelity EM solver -> adaptive sampling -> surrogate -> physical checks -> error map -> deployable model`

## Use cases
inverse design, optimization, control, digital twins, real-time optical systems.

## Key distinction
A surrogate is not accepted merely because test loss is low; it carries wavelength/geometry/material validity boundaries and physics residuals.

## Buyers
Photonics, RF, antenna and electromagnetic simulation teams.
