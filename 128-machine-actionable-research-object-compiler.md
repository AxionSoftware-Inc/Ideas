# Machine-Actionable Research Object Compiler

## Thesis
Compile a paper/project into a FAIR, machine-actionable object containing data, code, models, assumptions, provenance, licenses, environment and executable entry points.

## Output
A research object that an AI agent or another lab can inspect and reuse without reconstructing context manually.

## Checks
- persistent identifiers
- schema/type metadata
- provenance completeness
- executable environment
- license/access constraints
- links among figures, datasets, models and claims

## Buyers
Publishers, repositories, universities, research infrastructures.

## Strategic value
A value-added layer on top of federated FAIR infrastructure rather than another file repository.
